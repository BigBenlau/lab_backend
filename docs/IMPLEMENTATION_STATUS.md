# 實作與驗證範圍

## 目前實作

- 契約 7.1.0 包含四個公開 GET，以及管理／登入的 14 個操作模板（展開為 22 個操作）。以 SQLite10 保存三張內容表與兩張私有表。已實作管理員帳密、Session、Origin／CSRF、帳戶狀態核對及交易內審計。[API 契約](API.md) · [資料庫](DATABASE.md)
- 單機 Docker 部署共用一個 Nginx，兩個 Python API 分別使用獨立內網和資料掛載權限。正式與 HTTP 測試模式共用資料卷。兩個前端程式已由主倉庫追蹤；初始化來源由維護工具另外讀取。[架構](../ARCHITECTURE.md)
- 維護工具提供空庫初始化、首次內容預覽與套用、CSV 匯入、缺檔檢查、配對備份與恢復，以及內部存活／就緒、磁碟與備份監測。[部署與維護](OPERATIONS.md)
- `deploy/tls.sh` 以 `sites` 申請及續簽同時列出 `casino.ye.wang` 和 `crab.ye.wang` 的憑證，舊模式可繼續運作至成功切換。正式 gateway 透過 443 分流驗證握手，續期時平滑重載兩個入口。部署方可選 OOS 或主機 cron 定時執行。

## 已記錄的本機檢查

2026-11-23 以合成憑證、OpenSSL 和命令替身驗證 `sites`。首次簽發、舊模式切換、有效期內略過及進入 14 天窗口續期均已模擬。兩個域名在兩個端口的 SNI 及名稱核對參數符合預期。缺任一名稱、萬用字元或額外列入根域名／IP 的憑證均未寫入服務目錄，舊模式得以保留。專案基本檢查及手冊指令語法檢查通過。公網 DNS、生產簽發與瀏覽器連線仍須在部署環境確認。

2026-11-23 以暫存目錄、合成憑證、OpenSSL 及命令替身檢查新版線上續期。涵蓋舊 gateway 攔截、離線首次簽發、gateway 意外離線、線上雙識別續期、有效憑證略過、簽發失敗保留舊憑證，以及後台握手失敗後回復。專案基本檢查及 81 項 Python 回歸通過，包含兩種 gateway 模式的設定及映像建置白名單核對。TLS 情境全程使用命令替身，沒有建立網路連線。實際 SAS 在續簽與 reload 期間持續服務的情形、雲端排程及真實 ACME 驗證仍待部署方核對。

2026-11-23 使用暫存目錄、合成憑證與 OpenSSL 核對 dual 的 DNS 及 IP 識別。以命令替身檢查四組連線參數、略過新鮮憑證、進入短效窗口續簽及切回單一模式。模擬只簽到一個識別、後台 IP 握手失敗時，均保住先前的憑證及模式。此次未向 ACME 發出訂單或連線到實際入口。

2026-11-23 已檢查 gateway 產生的設定。正式模式只將誤入 443／27182 的明文 GET、HEAD 轉至各自的 HTTPS 網址，測試模式維持原有入口。專案基本檢查與四項 gateway 設定測試通過，實際 Nginx 回應及瀏覽器跳轉待部署核對。

2026-11-22 以暫存路徑、合成的 IP／域名憑證與 Docker、gateway 及連線命令替身檢查首次安裝、未到期略過、進入 72 小時窗口後續期、切換域名及退回 IP。已模擬簽發失敗、私鑰不配對和中斷後恢復。手冊的 shell 語法與 OOS YAML 結構已解析。真實公網驗證、Docker、阿里雲任務權限和通知仍須在 SAS 確認。

2026-11-19 的程式檢查紀錄包含靜態契約與 Compose 邊界檢查、81 項 Python 回歸及 24 項前後端 Node 模擬測試。使用合成資料、暫存目錄、程序內 ASGI、瀏覽器及 Docker 命令替身。覆蓋包括資料與檔案驗證、帳戶狀態、Origin／CSRF、HTTP 與 HTTPS 模式及固定端口。另有操作者回報首次來源預覽成功，尚未確認真實資料的套用與匯入。
