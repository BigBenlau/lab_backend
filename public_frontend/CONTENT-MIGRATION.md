# 首次內容整理

將已核准公開的成員、論文與合照整理為私人初始化來源。原始內容、個別成員的聯絡資料差異、待確認的作者身分及校對紀錄由內容管理員私下保存。官網只呈現確認可發布的欄位。

- 首次來源位於本機 `dist/data/lab.json` 及 `dist/assets/`，由維護工具唯讀掛載。先執行 `seed` 預覽，核對後才產生 CSV 和靜態檔案包。
- 成員與作者以 ID 核對。遇到同名、聯絡資料或校友年月有疑問，交由內容負責人確認。
- 分別執行 CSV 匯入、公開檔案安裝及缺檔檢查。運行後，管理頁維護 SQLite 業務內容，官網只讀公開 API、固定頁面設定以及指定的公開檔案。

成員來源的擷取腳本與預覽截圖可能包含個資。首次轉換統一使用主專案的 `scripts/prepare_initial_data.py`；本機產生的網站截圖放在 `public_frontend/previews/`，此路徑由根目錄 Git 規則排除。

預覽官網使用專案的 Docker 入口，讓原始初始化目錄保持私有。完整指令見[部署與內容維護](../docs/OPERATIONS.md)，前端對接見[公開 API](../docs/PUBLIC_API.md)。
